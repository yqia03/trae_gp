# 就地取材界面

遵守 AGENTS.md 的职责边界。读取 docs/competition/DESIGN.md，按需读取 BRIEF.md；实际素材路径见 assets/manifest.json。

1. 保留暖深棕、奶油文字与物件质感，首屏优先显示场景切换、图片/手动输入与主操作。使用真实组件，不能把 assets/reference/ui-desktop-concept.png 直接贴成页面。
2. 图中营养、时间或收藏文案不是需求。按规格补齐候选纠错、数量确认、人数/时间与基础用品；未实现入口不显示。
3. 结果突出菜单/用途、材料用量、步骤与条件。真实结果和固定样例来源同样醒目，不用成功措辞暗示尚未实现能力。
4. 加载反馈不编造百分比，禁用重复提交；输入改变后旧结果待更新，迟到响应不能覆盖新输入。失败要有重试、补充或手动路径。
5. 正文字号16px，说明至少13px，控件至少44px，状态不用纯颜色区分。按 DESIGN 的可读文字色，避免暗底上的低对比小字。
6. 实际打开1440×900或可用桌面尺寸，再检查390px宽度；走完整操作和一次错误恢复，确认无水平溢出、遮挡或失效按钮。

输出实际查看尺寸、执行路径、修改文件与剩余问题；没有浏览器能力时明确写视觉与交互未验证，不把截图当成功操作。
