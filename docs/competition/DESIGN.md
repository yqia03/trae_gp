# 就地取材 · 视觉与交互

## 参考判断

用户选择的 [ORYZO / Refero Styles](https://styles.refero.design/style/1f204e95-454a-437e-845b-c1b169d35607) 适合本项目：暖暗背景、奶油文字和物件摄影能突出普通材料的质感。该参考偏展示型网站；本项目保留其色彩与物件氛围，将交互改为首屏可操作的生活工具。

不要照搬全屏滚动、3D、极小标签、超大留白或原站字体资源。下述布局与中文排版是本项目的设计适配，不是原参考的逐项规范。未复制原站产品照片、品牌或站点源码。

| danger | #FFB4A8 | 可修正错误，本项目适配 |

主 CTA 使用奶油底、深棕文字。不要将原参考的 #6C5F51 用作卡片上小号正文。状态不能只用颜色表示，必须同时有文字或图标；焦点用明显的奶油色轮廓。

- 正文：系统字体 PingFang SC / Microsoft YaHei / sans-serif，16px、行高 1.6。减少字体下载依赖。
- 标题：可用本机 Songti SC / Noto Serif SC / serif，中文大标题 36–44px；无合适字体则用正文栈加粗。
- 分区标题 22–26px，卡片标题 18–20px；说明至少 13px。避免全大写英文替代中文信息。
- 圆角：大卡片 20px、输入 12px、按钮胶囊；细分隔线、轻阴影、无霓虹渐变。

## 桌面首屏（主要演示 1440×900，也检查 1366×768）

1. 顶栏约 64px：文字标识「就地取材」、一句短标语、可用的样例入口。未实现的导航不要占位。
2. 横幅 180–220px：主标题「把家里已有的，变成今天用得上的」，下方一句产品说明；右侧主视觉。叠加深棕渐变保障文字可读，图像位置靠右，不能让图上的物件盖住文字。
3. 横幅下：两个真实可切换的模式按钮「今晚吃什么」「物品第二人生」。用小标签解释两者共享「巧用替代」，不要做第三张空页面。
4. 工作区：左 38% 输入，右 62% 输出，间距 24px。左边图片预览不超过 140px 高，随后候选清单、关键约束、折叠基础用品与主 CTA；右边答案优先，不放无关统计。
5. 在 900px 高屏幕内能看见上传/示例入口、模式、确认清单和主要 CTA 的位置。长清单自然滚动整页，不做多层独立滚动区域。

主按钮随阶段改变：选择图片 → 识别图片 → 确认并生成今晚菜单 / 确认并生成改造方案。样例入口写「加载演示样例」，不能叫“AI 一键识别”却直接加载固定数据。

## 结果区

- 顶部：一句具体结果标题、人数/估时/来源、重新规划入口。示例与真实来源标记同等醒目，不藏在页脚。
- 食材：一餐的三项内容采用紧凑文字卡，不要求三张菜肴照片。每项展开查看用量和步骤；下方整餐制作顺序、用量汇总。
- 旧物：两张互斥方案卡，选中一种后展开其步骤与用量；另一方案明确为备选，不能同时显示为已选。
- 巧用替代：在确有缺料时贴近额外清单显示；无缺料时展示当前使用已有材料的简短理由。不要捏造缺料只为撑满版面。
- 成功不能只是一大段聊天文本。步骤编号、勾选状态、材料用量和条件必须能单独读懂。
- 复制时包含来源、输入概要、材料、步骤、估时与条件；页面不暴露 API 名称、JSON 字段或日志。

## 状态与小屏

空状态解释如何开始；识别中/生成中用真实阶段文字与轻量骨架，不能显示虚构进度百分比。错误贴近相关输入，给出重试/补充/手动录入路径。旧结果失效时盖上“输入已更改，请重新生成”，不得保留可执行的旧步骤勾选。

≤900px 改为单列，输入在前、结果在后；≤480px 表单两列降为一列。触控目标至少 44px，输入有可见标签，按钮支持键盘，加载中避免重复提交。缩到 390px 宽仍无水平溢出。

## TRAE 实施与查看

把品牌与演示图按 manifest 的路径复制进 public/assets；保留源资产。可以由框架在呈现时优化图片，但不把概念图切片拼成界面。

先做可运行交互，再按此规范完成色彩、间距、字形与素材。实际打开页面核对桌面与 390px 宽度，走一次完整输入和错误恢复；截图不是交互通过的证据。
