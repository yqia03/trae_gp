# 从这里交给 TRAE

**就地取材：把家里已有的，变成今天用得上的。**

准备包已包含需求、视觉规范、Gemini 接口契约与模型提示词、四张生成图片、两套演示场景、100分钟执行安排和验收脚本。当前是准备材料，尚无应用业务代码；真正的页面、接口、依赖安装和运行由 TRAE 完成。

## 现在怎么用

1. 在 TRAE 打开本目录：`/Users/uway/project/trae_gp`。
2. 比赛开始前可复制 [PROMPTS.md](PROMPTS.md) 的“赛前读取与环境确认”。
3. 将自己的 Gemini key 私下配置到项目 `.env.local`，不要贴进聊天、截图或 Git。变量名为 `GEMINI_API_KEY`；`GEMINI_MODEL` 建议填 `gemini-3.8-flash`。也可由 TRAE 在开工时创建空配置位置后再填写。不要把变量设为 NEXT_PUBLIC 开头。
4. 允许开始开发后，将 [PROMPTS.md](PROMPTS.md) 中“正式开工”整段发给同一个 TRAE 开发任务。它会读取本包，直接开始落地。
5. 开工后尽早测试一次真实 Gemini 小图请求。官方模型能力已经查证，但你的 key、额度、当前网络与模型访问权限尚未验证；固定样例不能代替真实调用通过。
6. 按 [TEAM.md](TEAM.md) 留出最后15分钟验收；[DEMO.md](DEMO.md) 提供90秒路演和出错恢复。

## 本包的实施基线

- **主场景**：冰箱食材 → 确认清单 → 一份主食两道菜、用量、步骤与制作顺序。
- **次场景**：旧物 → 确认清单 → 两种二选一的再利用方案。
- **贯穿亮点**：缺料时优先改用已有的或调整做法，重新核算资源。
- **默认栈**：Next.js 16 / TypeScript / Tailwind 4 / npm / Gemini 服务端 API。
- **视觉**：用户指定 Refero 的暖棕与奶油色，改成首屏可操作的工具界面。
- **不做**：账号、数据库、社区、交易、地图、运行时生图、第三个大型功能。

产品名、受众和具体栈是本包的规划默认值，用户可继续调整。其余已确认与官方规则的界限见 BRIEF。
